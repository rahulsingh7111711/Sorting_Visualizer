# Sorting Algorithm Visualizer 

A responsive web application built using **HTML, CSS, and JavaScript** to visually demonstrate how popular sorting algorithms work in real-time.

## Features

- Visualizes sorting algorithms: **Bubble Sort, Selection Sort, Insertion Sort**
- Interactive controls for:
  - Choosing sorting algorithm
  - Adjusting array size
  - Setting animation speed
- Smooth, real-time bar animations
- Clean UI and responsive layout

##  Technologies Used

- HTML5  
- CSS3 (Flexbox, transitions)  
- JavaScript (DOM manipulation, async/await for animations)
